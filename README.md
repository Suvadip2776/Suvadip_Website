# Suvadip Sana — Personal Website

Source for my personal academic website, deployed via GitHub Pages.

## Structure

- `index.html` — Home / about
- `research.html` — Publications, preprints, technical reports
- `cv.html` — Full CV (education, experience, awards, talks, service, skills)
- `teaching.html` — Teaching assistant experience
- `style.css` — Shared stylesheet
- `legacy/` — Old jemdoc-based site source, kept for reference

Deployment is handled automatically by `.github/workflows/jekyll-gh-pages.yml` on every push to `main`.
